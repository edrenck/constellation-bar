# Third-party notices

The macOS app has no third-party runtime dependencies. Its original source is covered by the [MIT license](LICENSE).

Weather data is provided by [Open-Meteo](https://open-meteo.com/) when configured and enabled; the weather panel displays attribution. AeroSpace, Tailscale and other optional integrations are separate products with their own licenses and terms.

Website dependency and component notices live in the [website repository](https://github.com/edrenck/constellation-bar-website).

## Typeset color palettes

No upstream theme renderer code is included. Omarchy’s collection informed the scheme selection; palette values come from the original projects.
