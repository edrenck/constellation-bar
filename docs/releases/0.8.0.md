# ConstellationBar 0.8.0 Beta

This beta adds configurable daily and system widgets, more appearance choices, and per-display customization improvements. Provider diagnostics and update recovery have also been strengthened.

## Highlights

- Add Timer, Keep Awake, Reminders, Keyboard, world clocks and configurable System metrics.
- Add terminal-inspired appearance palettes and improve layout previews and widget settings.
- Let providers update independently, show clearer availability and weather freshness, and keep failed configuration edits visibly unsaved until retried or reverted.
- Verify update downloads and signed app identity, then roll back if the replacement fails to confirm startup.

## Calendar change

Outlook now uses macOS Calendar access through EventKit. To show Microsoft calendars, add the account in **System Settings → Internet Accounts**, enable Calendars, and select the synced calendars in ConstellationBar. Calendars configured only inside Outlook are no longer read from Outlook's local cache. Existing calendar selections may need to be chosen again.

## Install and feedback

Download `ConstellationBar-0.8.0-universal.zip` and `SHA256SUMS`, verify the checksum, extract the app, and move it to Applications. The distribution workflow signs the universal app with Developer ID, notarizes and staples it, then checks Gatekeeper acceptance before attaching the archive to the release.

The automated build gate runs unit tests, native UI journeys and packaged-app startup on macOS 15 CI. Hands-on runtime coverage so far is macOS 27 on Apple Silicon. Intel, macOS 14/15, physical multi-monitor behavior, wake, VoiceOver and media permissions still need beta feedback. A signed installed-app update and relaunch should be smoke-tested before publishing this draft.

Report bugs with the app version, macOS version, chip, display arrangement and reproduction steps. Remove personal calendar, location and task details from screenshots and exported settings.
