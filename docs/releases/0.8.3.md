# ConstellationBar 0.8.3 Beta

This beta reduces background sampling work and improves interaction between ConstellationBar and the native macOS menu bar. Existing configuration is preserved.

## Changes

- Share menu-window scans across displays and cap them at five per second while retaining fast top-edge detection.
- Keep attached bar controls above the native menu interaction layer. A native reveal while the pointer is over the bar no longer moves its controls away; a deliberate dwell at the top edge lowers the bar and yields to the system menu.
- Fetch process details only while a System, CPU or Memory panel is open. Closed CPU/Memory panels skip unrelated metric reads.
- Refresh Calendar caches after backward clock changes, clear retained agenda data after permission loss, and prevent expired media fallback tracks from reappearing after clock changes.

## Validation and compatibility

Local compilation and the required native UI/startup gate passed all 363 tests. CPU and memory probes each show zero Mach send-right growth over 1,024 reads. The owner completed manual verification of the side branch before approving this release preparation. These checks do not establish compatibility across every supported OS/device combination.

The app targets macOS 14+ with Apple Silicon and Intel binaries. Intel/minimum-OS execution, broader physical multi-display and permission/device transitions, VoiceOver, long-running energy profiling and distributed signed-update/rollback qualification remain incomplete. Private SkyLight/MediaRemote behavior can vary by macOS version. Timer completion is visual only.

Distribution artifacts are produced by the Developer ID signing/notarization workflow, which requires accepted notarization, stapling and Gatekeeper verification. Use `ConstellationBar-0.8.3-universal.zip` and its matching `SHA256SUMS` from this release, rather than a CI development artifact.
