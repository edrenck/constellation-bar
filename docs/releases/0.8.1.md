# ConstellationBar 0.8.1 Beta

Fix fullscreen hiding for native macOS fullscreen, including YouTube video fullscreen in Arc, without requiring Accessibility access.

With fullscreen hiding enabled, the bar hides on displays whose active Space is native fullscreen and stays visible on ordinary desktop Spaces. Maximized and borderless windows no longer trigger hiding based on their size.

Detection uses read-only, dynamically loaded private SkyLight APIs. If those queries are unavailable on a macOS version, the bar stays visible.

## Validation

Automated regression tests cover per-display native fullscreen classification, return to desktop, and unavailable queries. The native query was also checked live with Arc YouTube fullscreen on Apple Silicon. Multiple physical monitors, Split View, Intel, and older macOS versions have not been verified hands-on.

## Install

Download `ConstellationBar-0.8.1-universal.zip` and `SHA256SUMS`, verify the checksum, extract the app, and move it to Applications. The universal app is Developer ID-signed, notarized, and stapled. Existing configuration is preserved.
