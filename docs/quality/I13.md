## Reproduced problems and resulting behavior

Three native regression methods reproduced **six assertion failures, zero unexpected failures** before application edits. At 340×300, the body viewport was 198 points high: Calendar's first event began at y=197 and Music transport controls at y=203–207. Their content was scrollable but primary tasks were not initially visible. The same test suite confirmed that process rows changed to ascending CPU order while the label stayed “CPU ↓”; Network inherited that irrelevant disabled control.

`MiniAppPanel` now detects a compact body viewport, including a height-only resize, adjusts spacing and rebuilds through existing logical-focus restoration. Music's feature content uses 48-point artwork instead of 148 in compact mode, bounds metadata, and puts transport before progress and secondary detail. Multiple sources, long titles/artists/albums and the selected source/tab survive resizing. Full strings remain available through native text/accessibility and tooltips where displayed text is truncated. Calendar combines its date/navigation header, retains all seven week controls and prioritizes the first event or empty agenda. Weekday text increases from 9 to 11 points. In short permission states, access actions precede long explanations. Additional details remain scrollable; the implementation does not promise every field above the fold.

`SystemPanelContent` replaces the System extension's mutable shell state. It owns typed tab, history-range and process-sort choices, holds its host weakly, and supplies refresh closures using current snapshots. Memory initializes on its own tab. CPU's label and accessibility value reflect ascending/descending order, with a stable control identifier for focus restoration. Memory and Network show their own headings without an irrelevant CPU sort action. Native preview navigation now uses the same tab control rather than changing a generic shell field.

The [architecture guide](../ARCHITECTURE.md) documents the ownership and compact-layout path. Audio/VPN and other remaining shared panel state are still open; folders remain conventions within one executable target.
