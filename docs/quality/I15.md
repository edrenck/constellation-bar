# I15 — 0.8.2 beta candidate and host-port resource correction

Scope is frozen for a beta preparation PR targeting `beta-release`. This pass corrects the confirmed resource leak, records the candidate's checks and prepares version/release metadata. Polling optimization, further architecture changes and optional UI features are deferred.

## Reproduction and fix

Before application edits, two native tests measured host send-right reference counts with `mach_port_get_refs`. 1,024 CPU reads increased the count from 3 to 1,027; 1,024 memory reads increased it from 4 to 1,028. Both tests failed, confirming one retained right per read. Logs are retained in `.build/production-readiness/i15/mach-before.log`.

Each OS-reading scope now stores its `mach_host_self()` result and uses `defer` to release that send right with `mach_port_deallocate`, including early error exits. No long-lived shared port or new mutable service is introduced. This follows the ownership pattern in [Apple's IOKit source](https://github.com/apple-oss-distributions/IOKitUser/blob/main/IOKitLib.c). Both focused and full native runs now show **2 references before and after 1,024 reads** of each kind, with zero growth. This stress check establishes these call scopes' ownership; it does not establish the whole application's long-running memory/energy behavior.
