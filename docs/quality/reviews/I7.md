Prioritized findings:

The panel formats every deadline with a time, so an untimed reminder can appear due around 11:59 PM. Preserve date-only metadata separately from the comparison boundary, and test both overdue behavior and date-only presentation. **Static inference; the inspected screenshots contain timed reminders.** Evidence: [AppleRemindersReader.swift:27](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/AppleRemindersReader.swift:27), [RemindersModels.swift:4](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/RemindersModels.swift:4), [DailyPanels.swift:53](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/DailyPanels.swift:53).

The shared interval defaults to two seconds and accepts values up to sixty seconds, so the visible countdown jumps and completion feedback can lag by that interval despite a correct monotonic deadline.
