Prioritized findings:

1. **P1 — A CPU sampling failure can terminate the application.**  
   `CPUCounters.current()` returns zero counters when `host_statistics` fails. After a successful sample, subtracting those unsigned values from the previous counters underflows before `max` can protect the calculation. This affects the commonly enabled System widget. Return an explicit failed reading, preserve or reset the baseline, and guard decreasing counters before subtraction. Add an injected-reader regression covering success → failure → recovery. **Static inference; not reproduced during execution.** Evidence: [SystemUtilities.swift:66](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Core/SystemUtilities.swift:66), [MetricsProvider.swift:34](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/System/MetricsProvider.swift:34).

2. **P2 — Failed or truncated VPN output can still produce a connected badge.**  
   `SystemVPNIntegration` parses `scutil` output before checking success. `VPNProvider` then treats any resulting connection as available, so a failed command containing a partial connected-service listing can appear connected in the bar. The control preflight similarly parses unchecked output. Reject unsuccessful results before parsing; distinguish unavailable data from a successful empty listing. **Static inference.** Evidence: [VPNProvider.swift:17](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/VPN/VPNProvider.swift:17), [VPNProvider.swift:27](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/VPN/VPNProvider.swift:27), [VPNProvider.swift:47](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/VPN/VPNProvider.swift:47).

3. **P2 — Hiding Agent Status does not invalidate queued SSH work.**  
   `AgentStatusProvider` inherits the empty `deactivate()` implementation. Removing its last active display therefore never reaches the remote monitor’s disable path, which clears entries, cancels queued operations and advances its generation. Queued probes can continue while the widget is hidden. Implement provider deactivation and test removal through `SystemMonitor`, including multiple queued hosts. **Static inference.** Evidence: [AgentStatusProvider.swift:76](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Agents/AgentStatusProvider.swift:76), [SystemMonitor.swift:12](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Core/Widgets/SystemMonitor.swift:12), [RemoteAgentStatusMonitor.swift:66](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Agents/RemoteAgentStatusMonitor.swift:66). The existing [remote disable test:44](/Users/edrenck/constellation-bar/Tests/ConstellationBarTests/RemoteAgentStatusTests.swift:44) calls the monitor directly.

4. **P2 — Timer feedback follows the general provider refresh interval.**  
   The countdown remains mathematically correct, but its visible remaining time and completion state change only when sampled. 6. **P2 — Date-only reminders acquire an invented displayed time.**  
   The reader converts a date-only deadline to the final second of its day to calculate overdue status, but the model discards the original precision. The panel then formats every deadline with a time, presenting an untimed task as due around 11:59 PM. Preserve date-only metadata separately from the overdue boundary and format it accordingly. **Static inference.** Evidence: [AppleRemindersReader.swift:29](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/AppleRemindersReader.swift:29), [RemindersModels.swift:4](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/RemindersModels.swift:4), [DailyPanels.swift:53](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/DailyPanels.swift:53).

7. **P3 — Keep Awake’s display checkbox has an ambiguous active-session contract.**  
   The checkbox remains editable during a session but has no action; only pressing a duration button reads its value. Checking it can therefore suggest that the current session now prevents display sleep when nothing changed. Apply the change to the current session or clearly label it as an option for the next session. **Static inference; the active-state fixture exposes the affordance.** Evidence: [DailyPanels.swift:28](/Users/edrenck/constellation-bar/Sources/ConstellationBar/Widgets/Daily/DailyPanels.swift:28), [mini-app-keepAwake.png](/Users/edrenck/constellation-bar/.build/production-readiness/i5/previews/mini-app-keepAwake.png).
