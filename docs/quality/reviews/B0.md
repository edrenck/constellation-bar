## Prioritized findings

1. **Basic action labels truncate in several panels — observed in fresh native-rendered fixtures.** Timer displays `5…`, `15…`, `25…`, `Pa…`, `Re…`. Keep Awake, Keyboard and Reminders similarly truncate duration and launch controls, despite unused panel space. `WidgetActionButton` adds drawing padding without matching intrinsic sizing: `DesignSystem/PanelComponents.swift:11,49–54`; `Widgets/Daily/DailyPanels.swift:11–19`. `DailyWidgetPanelTests.swift:22–28` checks stored title/action routing, missing visible truncation.
2. **AeroSpace failures can appear successful — static inference by reviewer.** Only the first workspace query checks success. Subsequent focus/window calls consume output after failure, timeout or truncation, then report connected; action failures are discarded. `Shell/Workspaces/AeroSpaceProvider.swift:34–46,66–70`.
3. **Settings do not always preserve user intent — static inference by reviewer.** Valid imported refresh intervals are rounded to four UI presets, then unrelated Application changes write the approximated value. Invalid coordinate text is ignored and previous values restored with a saved status. `Settings/ConfigurationWindowController.swift:201–202,408–413,441–444`.
4. **Diagnostics and persistence coverage are inconsistent.** The diagnostics UI omits Timer, Keep Awake, Reminders and Keyboard even though its model supports them. Calendar filtering writes directly to UserDefaults, outside JSON export and Undo. `Settings/DiagnosticsSettings.swift:37`; `Core/Widgets/IntegrationDiagnostics.swift:35`; `Widgets/Calendar/CalendarPanel.swift:21–27`.
5. **Accessibility foundations exist; complete operation remains unverified.** Custom bar controls expose roles, values and press actions; material/motion preferences are respected. Generic settings rows do not associate labels with controls, and metric graphs expose a generic name without history information. Direct press-action tests do not establish keyboard traversal or VoiceOver usability. `DesignSystem/MaterialControl.swift:32`; `Settings/SettingsForms.swift:33`; `Widgets/System/SystemPanel.swift:27`.

## Architecture observations

Provider serial ownership/coalescing and persistence retry/revert are concrete strengths, supported by meaningful test source. The architecture guide helps a backend developer find the provider entry point. Central feature switches, broad shared panel state and documentation drift weaken discoverability; `docs/WIDGETS.md:45` references nonexistent `MiniAppModels.swift`.

Private MediaRemote/SkyLight APIs and private Codex metadata remain compatibility risks. MediaRemote's bounded subprocess isolation reduces the potential failure impact.
