## Prioritized findings

All findings below are static inferences unless otherwise stated; they need focused reproduction and triage before treating them as confirmed runtime defects.

1. **Provider sampling includes disconnected displays and unused shared layouts.** `widgetsForSampling` unions global layout and every enabled saved override, while rendering selects a narrower set of screens. A widget only on a disconnected monitor can keep sampling; active Keep Awake may retain an assertion after its last visible presentation disappears. Resolve sampling from effective target-display layouts and refresh it on display changes. `Core/Configuration/DisplayConfiguration.swift:5`, `Shell/ScreenBarController.swift:33`, `Widgets/Daily/KeepAwakeProvider.swift:43`. High static confidence; no disconnect runtime check.
2. **Window pickers silently omit larger collections.** Workspace overview builds nine cards; window switcher builds eight rows, with no scroll, overflow action or indication of additional windows. `Shell/Workspaces/WindowOverview.swift:30,68`. High static confidence.
3. **Transient Reminders failures become authorization states.** Any read error replaces cached state with default `authorized == false`, so the panel offers permission when a timeout/read failure is the actual issue. Separate authorization from fetch health and provide retry/staleness feedback. `Widgets/Daily/RemindersProvider.swift:74`, `Widgets/Daily/DailyPanels.swift:37`. High static confidence.
4. **Calendar handoff loses selected event.** Open in Calendar/Outlook supplies only a bundle identifier, not the selected event. Implement event navigation or label the action Open Calendar/Outlook. `Widgets/Calendar/CalendarPanel.swift:74`, `Shell/Panels/MiniAppPanel.swift:219`. High static confidence.
5. **Settings accessibility needs direct audit.** Several shared form rows provide adjacent visual labels without explicit control labels/title associations. Widget reordering and daily fields have explicit labels, so coverage is uneven. `Settings/SettingsForms.swift:33`, `Settings/DisplaySettingsEditor.swift:128`. Static concern; no VoiceOver test.
