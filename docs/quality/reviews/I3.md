## Prioritized findings

1. **Discoverable keyboard entry — static reachability concern.** Individual controls implement Return/Space and accessibility press, and pinned panels accept Escape. The bar opts out of window cycling, while menus expose settings and quitting without a clear Focus Bar command. Add an entry command and verify keyboard-only entry → traversal → opening → dismissal. This is not a demonstrated keyboard failure.
2. **Core Audio error state — source evidence.** `AudioProvider` returns default state on enumeration errors, leading to “No output”/“No devices available” and missing-output diagnostics without the underlying failure. Preserve the operation and OSStatus in an explicit unavailable state with retry guidance. No actual device failure was reproduced by this review.
3. **Panel overflow and feedback — fixture observation plus static risk.** The Agent Status fixture's initial viewport cuts through its lower explanatory disclosure without a visible scroll cue. Content is scrollable; this is not missing data. Separately, a wrapping action-error label occupies an 18-point footer, risking clipped recovery instructions. Add a clear overflow affordance and expandable feedback space.
4. **Composition and feature state — architecture.** `BarController` constructs `SystemMonitor`; default providers find `WidgetServices.shared`. `MiniAppPanel` owns unrelated media, calendar, VPN and system selection state. Explicit service injection and feature-owned state would make changes safer to isolate. No runtime failure is asserted.
5. **Calendar return flow.** Add a Today action beside previous/next navigation and disable endpoint controls rather than accepting clicks that only show a footer message.

The supplied logs confirm **225 XCTest tests and 13 Python tests passed**, with empty preview runtime output. Tests cover stalled-provider isolation, serialization, deactivation, stale results, failed saves/Undo, visible customization and actual executable startup. The reviewer did not run them independently. Physical multi-monitor operation, older macOS/Intel, live glass, VoiceOver and signed-update compatibility remain unestablished.
