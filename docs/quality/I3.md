## Behavior and ownership

[ConfigurationEditingSession](../../Sources/ConstellationBar/Settings/ConfigurationEditingSession.swift) owns draft configuration, the saved baseline, raw form input, validation, the injected persistence operation, failure state and a 30-entry Undo history. The AppKit window renders that state and routes actions. Only a successful write returns a configuration that the controller may apply to the desktop. Session tests instantiate no windows.

Weather, World Clock and Timer edits validate as a complete candidate before changing typed preferences or reaching persistence. Invalid text remains visible through page/display changes, retries and unrelated edits. Empty comma segments cannot silently disappear. Correcting the form saves all pending edits as one Undo entry. Import explicitly replaces pending raw input; export validates the same candidate without advancing live state or Undo. External reloads clear obsolete Undo history and establish the latest saved baseline; an open failed-save form survives, and Revert uses that latest baseline.

The collapsed workspace selector now uses the shared `WidgetActionButton`. Its text follows the selected theme rather than the inherited window appearance. Fresh native light renders visibly retain dark text. A pixel-based test checks the rendered title against its theme background with the opposite window appearance for all five appearance identifiers and both Native modes. This is an opaque rendering check, not live material contrast qualification.

Shared settings form rows attach an explicit accessibility name and title-element relationship. Existing descriptive names are retained, checkbox names include their visible descriptive titles, and Latitude/Longitude have separate names. Native tests inspect these associations. Full VoiceOver operation remains unverified. Window cards and switcher rows expose full app/title/workspace text as tooltips while retaining their existing full accessibility names.

README and the configuration reference now describe the current display picker, Left/Center/Right placement, schema 5 and truthful Calendar/Outlook handoff. The architecture guide maps concrete classes to backend responsibilities and documents the session transaction boundary. No generic inheritance framework or extra package layer was introduced.
