## Reproduced behavior

Before application edits, three native tests reproduced four behavior failures: a fresh Timer said Resume, a long action failure put both Timer controls below the initial 320×280 viewport, and Escape for a second application window closed the pinned Timer. The Escape regression uses actual `NSApp.sendEvent`, real native windows and the production local monitor, with an independent monitor proving delivery. It does not establish hardware or active-app responder routing. An earlier witness-order assumption produced one extra instrumentation failure; both original logs are retained.

## Resulting implementation

`CountdownState` has explicit Ready, Running, Paused and Finished phases. An immediate pause remains Paused even when its remaining duration equals the original duration. Reset returns to Ready; resume cannot restart a finished or fresh timer or extend a running deadline. Invalid starts preserve the active countdown. Feature-owned `TimerPanelContent` binds Start/Pause/Resume/Start again and routes the corresponding command. Its primary action and Reset precede presets and explanatory text. The bar icon, inspector status and diagnostics distinguish Ready from Paused.

The shared panel presents action errors in its pinned footer, with a one-line preview, complete native text/tooltip and an explicit Details action. Long messages no longer enlarge the scroll document or displace feature controls. `ErrorDetailsPresenter` provides the same bounded, selectable, scrollable full-error sheet for panel actions and settings-save failures. It prevents duplicate sheets and opens only after the user's click. Details sizes from its native content so Typeset's label fits.

The overlay's application-local Escape handler now checks visible pinned ownership, the event's window, modifier keys and attached-sheet state. Escape for another window, modified Escape and sheet interactions propagate; plain Escape for the owning panel closes it and removes the monitor. [Apple's local monitor contract](https://developer.apple.com/documentation/appkit/nsevent/addlocalmonitorforevents(matching:handler:)) and [sheet API](https://developer.apple.com/documentation/appkit/nsalert/beginsheetmodal(for:completionhandler:)) informed these boundaries.

The [architecture map](../ARCHITECTURE.md) and [daily widget guide](../DAILY_WIDGETS.md) describe the final contracts. Audio/VPN and remaining shared panel/settings ownership remain open.
